# Scenario SC-02 — Fail to reject friend request due to invalid user

**Feature:** FE-03 · **Use case:** UC-03

## Summary

This scenario covers the failure path when a user attempts to reject a friend request for a user that cannot be resolved (e.g., does not exist or invalid credentials).

## Given

- A `client` (`cl`) is authenticated and connected to the `server`.
- The `server` instance (`s`) is running.

## When

- The user invokes `RejectFriendRequest` on the `server` with a `targetID` or `targetName` that corresponds to an unresolvable user.

## Then

- The `server` fails to resolve the user.
- The `server` reports an error back to the client using `cl.err(err)`.
- The rejection process is halted, and `cl.RejectFriendRequest` is not called.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Calls `RejectFriendRequest(cl, targetID, targetName)` | `server/server.go:594` |
| 2 | System (`server`) | Calls `s.resolveUser(targetID, targetName)` | `server/server.go:595` |
| 3 | System (`server`) | `resolveUser` returns error | `server/server.go:595-596` |
| 4 | System (`server`) | Calls `cl.err(err)` | `server/server.go:597` |
| 5 | System (`server`) | Returns from function | `server/server.go:598` |
