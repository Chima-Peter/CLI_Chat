# Scenario SC-02 — Fail when target user does not exist

**Feature:** FE-03 · **Use case:** UC-01

## Summary

The friend request fails if the target user ID or nickname cannot be resolved. This ensures that a request can only be sent to a valid, existing user.

## Given

- The user is authenticated in the system.
- The user provides a target identifier (ID or nickname) that does not match any existing user.

## When

- The user initiates a friend request action targeting the non-existent user.
- The `server.SendFriendRequest` method is invoked.

## Then

- The system fails to resolve the target user.
- An error is returned to the calling client, preventing the request from proceeding.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Calls `SendFriendRequest` with invalid target | `server/server.go:576` |
| 2 | Server | `s.resolveUser` fails to find user | `server/server.go:577` |
| 3 | Server | `cl.err(err)` is called and function returns | `server/server.go:578-580` |
