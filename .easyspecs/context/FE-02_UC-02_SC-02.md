# Scenario SC-02 — Fail to join private room with incorrect password

**Feature:** FE-02 · **Use case:** UC-02

## Summary
When a user attempts to join a private room by providing an incorrect password, the system prevents the join operation and returns an error message to the user indicating an incorrect password was provided.

## Given
- A private room exists that requires a password.
- A user attempts to join this room.
- The user provides a password that does not match the room's password.

## When
- The user submits the request to join the room with the incorrect password.

## Then
- The system validates the password.
- The join attempt is rejected.
- The client receives an error message: "Incorrect password."
