# Scenario SC-05 — Fail when target user is blocked

**Feature:** FE-03 · **Use case:** UC-01

## Summary

When a user attempts to send a friend request to another user, the system checks if either the initiator has blocked the target, or if the target has blocked the initiator. If either condition is true, the request fails, and an error message is returned to the user.

## Given

- User A and User B exist in the system.
- The system has mechanisms to track blocked users (`blocked_users` map in the `client` struct).
- User A is attempting to send a friend request to User B.

## When

- User A calls `SendFriendRequest(User B)`.
- The system executes the `isBlockedWith(User B)` check to verify blocking status.

## Then

- If User A has blocked User B (`selfBlocked` is true), the operation terminates with an error: "You have blocked [User B Nickname]. Unblock them to send a friend request."
- If User B has blocked User A (`blockedByOther` is true), the operation terminates with an error: "You cannot send a friend request to [User B Nickname]."
