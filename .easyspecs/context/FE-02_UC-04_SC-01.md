# Scenario SC-01 — User leaves room successfully

**Feature:** FE-02 · **Use case:** UC-04

## Summary

The user initiates a request to leave a room. The system verifies that the user is currently a member of the room, removes the user from the room, notifies the user of success, and broadcasts a message to other room members informing them of the user's departure.

## Given

- The user is already a member of a room (`cl.my_rooms[r.id]` exists).

## When

- The `LeaveRoom(cl *client)` method is called on the room instance.

## Then

- The user is removed from the room (`r.DeleteMember(cl)`).
- The user receives a success message "Left room.".
- Other room members are notified that the user left the room via a broadcast.
