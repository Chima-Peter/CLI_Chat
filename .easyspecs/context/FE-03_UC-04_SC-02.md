# Scenario SC-02 — Fails when friend request does not exist

**Feature:** FE-03 · **Use case:** UC-04

## Summary
Attempting to cancel a non-existent friend request results in an error message to the user, as the server validates that the request exists in the sender's `sent_friend_request` map before proceeding.

## Given
The sender does not have an active pending friend request sent to the specified user.

## When
The sender initiates a request to cancel the friend request for a user who was not previously targeted with a request.

## Then
The system denies the request and returns an error message: "You have not sent a friend request to this user."

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Sender | Initiates cancel request for target user | `server/client.go:138` |
| 2 | System (Server) | Validates `sent_friend_request` map for target user ID | `server/client.go:139-141` |
| 3 | System (Server) | Fails validation because ID not in map | `server/client.go:142` |
| 4 | System (Server) | Sends error message to user | `server/client.go:143` |

## Related code and tests
