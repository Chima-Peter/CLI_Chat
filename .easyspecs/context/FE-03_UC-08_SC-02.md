# Scenario SC-02 — Fail to remove a user who is not a friend

**Feature:** FE-03 · **Use case:** UC-08

## Summary

The user attempts to remove another user from their friend list. If the target user is not currently in the user's friend list, the system rejects the request and informs the user of the error.

## Given

The user has a friend list, and the target user is **not** present in that list.

## When

The user initiates the `DeleteFriend` action with the target user as the argument.

## Then

The system detects that the friendship relationship does not exist, terminates the operation, and sends an error message: "You are not friends with [nick]."

| Step | Actor / system | Expected | Evidence |

| 3 | System | Detects absence of friendship | `server/client.go:242` |
