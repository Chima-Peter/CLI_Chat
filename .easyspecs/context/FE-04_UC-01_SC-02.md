# Scenario SC-02 — Switch to existing friend context

**Feature:** FE-04 · **Use case:** UC-01

## Summary

The user successfully switches their active communication context to an existing friend.

## Given

- The user is currently in a conversation or idle.
- The target user is already in the requester's friend list.

## When

- The user sends a command to switch context to the specified friend (e.g., `set context friend <friend_nick>`).

## Then

- The server resolves the friend's identity.
- The server verifies that the target user is in the requester's friend list.
- The client's active context is updated to `contextFriend`.
- The client's active friend is updated to the target friend.
- The server sends a confirmation message to the client.
