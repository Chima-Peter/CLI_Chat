# Scenario SC-03 — Try to join the room already joined

**Feature:** FE-02 · **Use case:** UC-01

## Summary

This scenario covers the behavior when a client attempts to join a room that they are already currently connected to. The system prevents the action and notifies the user.

## Given

- The client `cl` is already connected to a room (`cl.room != nil`).
- The client attempts to join the room `r` which is equal to `cl.room` (`cl.room.id == r.id`).

## When

- The client calls `r.JoinRoom(cl)`.

## Then

- The system detects the client is already in the room.
- An error message is sent to the client: `"You are currently in this room: %s"`.
- The `JoinRoom` operation terminates early.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Calls `JoinRoom(cl)` | `server/rooms.go:76` |
| 2 | System | Checks if client is already in a room (`cl.room != nil`) | `server/rooms.go:82` |
| 3 | System | Checks if the room to join is the current room (`cl.room.id == r.id`) | `server/rooms.go:83` |
| 4 | System | Returns error to client | `server/rooms.go:84-85` |
