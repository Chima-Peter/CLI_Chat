# Scenario SC-03 — Attempt to block self

**Feature:** FE-05 · **Use case:** UC-01

## Summary

The user attempts to block themselves, which should be prevented by the system.

## Given

A user session is active (`client` instance).

## When

The `BlockUser` method is invoked with the current client as the target.

## Then

The system detects that the user is attempting to block themselves and returns an error: "You cannot block yourself."

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Call `BlockUser` with `target == cl` | `server/client.go:323` |
| 2 | System | Detects `cl.id == target.id` | `server/client.go:324` |
| 3 | System | Returns "You cannot block yourself." error | `server/client.go:325` |

## Related code and tests

The logic for preventing a user from blocking themselves is implemented in the `BlockUser` method in `server/client.go`.
