# Scenario SC-03 — Fails when request exists but target not in pending

**Feature:** FE-03 · **Use case:** UC-04

## Summary
This scenario covers the failure case where a user attempts to cancel a friend request that appears in their sent list, but the target user does not have a corresponding pending friend request from the sender.

## Given
- The sender has sent a friend request to the target user, which is reflected in `sender.sent_friend_request` (`server/client.go:140`).
- The target user's `pending_friend_requests` does not contain the sender's ID (`server/client.go:148`).

## When
- The sender invokes the `DeleteFriendRequest` function (implicitly via the system workflow) to cancel the request to the target user.

## Then
- The system checks if the target has the sender in their pending requests (`server/client.go:148`).
- Since the sender is not in the target's pending list, the condition `if !ok` evaluates to true (`server/client.go:150`).
- The system returns an error to the sender: `"Error deleting pending requests. Record not found."` (`server/client.go:151`).

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Sender | Initiates cancel request to Target | N/A |
| 2 | System | Validates request existence in sender's list | `server/client.go:140` |
| 3 | System | Validates sender's ID in Target's pending list | `server/client.go:148` |
| 4 | System | Detects missing record in Target's pending list | `server/client.go:150` |
| 5 | System | Returns error message to sender | `server/client.go:151` |
