# Scenario SC-02 — Fail: user not found

**Feature:** FE-03 · **Use case:** UC-02

## Summary
This scenario describes the failure path when a user attempts to accept a friend request from a target user that cannot be resolved in the system (e.g., user does not exist or invalid ID/name).

## Given
- The user is authenticated in the system.
- The user has a pending friend request from a specific source, but attempts to accept a request from a target user that is unknown or cannot be found by the system.

## When
- The user triggers the `AcceptFriendRequest` action for a non-existent or unresolvable `targetID` and `targetName`.
- The `server.AcceptFriendRequest` method is called.

## Then
- The system fails to resolve the target user.
- The system sends an error message back to the client via `cl.err(err)`.
- The friend request is not accepted.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Attempts to accept friend request with invalid `targetID`/`targetName` | `server/server.go:585-592` |
| 2 | Server | `AcceptFriendRequest` calls `s.resolveUser` | `server/server.go:586` |
| 3 | Server | `resolveUser` returns an error | `server/server.go:586` |
| 4 | Server | `cl.err(err)` is called, notifying client of the failure | `server/server.go:588` |
