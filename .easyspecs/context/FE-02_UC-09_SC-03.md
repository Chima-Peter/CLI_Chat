# Scenario SC-03 — Decline invite when already in room

**Feature:** FE-02 · **Use case:** UC-09

## Summary
When a user attempts to decline an invite for a room they are already a member of, the system informs them that they are already in the room and cleans up the invite.

## Given
The user has received an invitation to a room, and the user is already a member of that room.

## When
The user sends a request to decline the room invitation.

## Then
The system sends an error message "You are already a part of this room" to the user, and the invite is removed from the user's and the room's invite lists.

| Step | Actor / system | Expected | Evidence |

| 1 | User | Requests to decline the invite | `server/rooms.go:345` |
