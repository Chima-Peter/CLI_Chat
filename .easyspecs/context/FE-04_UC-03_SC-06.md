# Scenario SC-06 — Error when friend context is null

**Feature:** FE-04 · **Use case:** UC-03

## Summary
The system returns an error when the user attempts to send a message while in `contextFriend`, but the `friend` object is nil.

## Given
The user has set the current context to `contextFriend`, but no friend has been successfully resolved or assigned to the current session (i.e., `friend` is nil).

## When
The user sends a message using `sendMessage`.

## Then
The system checks if `friend` is nil. If it is, an error message "use /switch friend <name> before sending a message" is sent to the client, and the message sending process is aborted.
