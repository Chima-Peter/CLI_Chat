# Scenario SC-02 — Send message to friend context

**Feature:** FE-04 · **Use case:** UC-03

## Summary

The user sends a message to their currently selected friend context. If a friend context is active, the message is sent directly to that friend. If no friend is set, an error is returned.

## Given

- The client has established a connection and is authenticated.
- The client has switched to the `friend` context using the `/switch friend <name>` command.
- A valid friend is currently set in the client's context (`cl.current_friend`).

## When

- The user sends a message in the console.
- The system calls the `SendContextMessage` function in `server/server.go`.
- The system checks the current context, which is `contextFriend`.

## Then

- The system verifies that a friend is currently active (`friend != nil`).
- If active, the system calls `cl.MessageFriend(friend, message)` to deliver the message.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Sends message in console | `server/server.go:370` |
| 2 | System | Detects context `contextFriend` | `server/server.go:391` |
| 3 | System | Checks if `friend` is set | `server/server.go:392` |
| 4 | System | Calls `cl.MessageFriend` | `server/server.go:396` |

## Related code and tests
