# Scenario SC-02 — Try to join a full room

**Feature:** FE-02 · **Use case:** UC-01

## Summary
The user attempts to join a room that has reached its maximum capacity. The system detects that the room is full and denies access, returning an error message to the user.

## Given
- The user is authenticated.
- A target room exists and has reached its maximum number of members.

## When
- The user sends a request to join the target room.

## Then
- The server validates the room capacity.
- The server returns an error message: "Room is full (max %d members)."
- The user is not added to the room.
