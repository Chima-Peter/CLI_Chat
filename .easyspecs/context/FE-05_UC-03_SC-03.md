# Scenario SC-03 — Check status of blocked offline user

**Feature:** FE-05 · **Use case:** UC-03

## Summary
The system verifies the current status (offline) and block status (blocked) of a target user, and communicates this information back to the requester.

## Given
- The requester (`cl`) is an authenticated user.
- The target user (`target`) is in the requester's `blocked_users` list.
- The target user (`target`) has `online` set to `false`.

## When
- The requester calls `GetUserStatus(target)` on the server.

## Then
- The server determines the user is blocked (`isBlocked = true`).
- The server determines the user is offline (`online = false`).
- The requester receives a message with `blocked: true` and `online: false` for the target user.
