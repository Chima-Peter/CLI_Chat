# Scenario SC-04 — Attempt switch to user who is not a friend

**Feature:** FE-04 · **Use case:** UC-01

## Summary

The system prevents switching the active context to a user if the current client is not friends with the target user.

## Given

- The client is authenticated.
- The client wants to switch their active conversation context to a specific user.

## When

- The user initiates a request to switch context to a target user.
- The system verifies the friendship status between the client and the target user.
- The target user is **not** present in the client's friend list.

## Then

- The switch request is rejected.
- An error message "you are not friends with [nick]" is returned to the client.
