# Scenario SC-01 — Successfully send a friend request

**Feature:** FE-03 · **Use case:** UC-01

## Summary

A user (User A) initiates a friend request to another user (User B). Upon successful validation, the request is recorded in both users' state, and both receive a confirmation message.

## Given

Both users are authenticated. User A intends to send a friend request to User B. The users are not currently friends, no request is already pending, and neither party has blocked the other.

## When

User A calls `SendFriendRequest(friend *client)` with User B as the argument.

## Then

- The friend request is added to User A's `sent_friend_request` map and User B's `pending_friend_requests` map.
- User A receives a confirmation message: "Friend request sent to <User B>."
- User B receives a notification message: "Received a friend request from <User A>."

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User A | Validates request conditions (not self, not blocked, not already friends/pending). | `server/client.go:70-101` |
| 2 | System | Records request in `sent_friend_request` (User A) and `pending_friend_requests` (User B). | `server/client.go:103-109` |
| 3 | System | Sends confirmation to User A. | `server/client.go:111` |
| 4 | System | Sends notification to User B. | `server/client.go:112` |
