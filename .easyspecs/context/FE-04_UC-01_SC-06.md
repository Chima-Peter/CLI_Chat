# Scenario SC-06 — Attempt switch with invalid context type

**Feature:** FE-04 · **Use case:** UC-01

## Summary
The system validates the context type during a switch operation. If the provided context type is neither a room nor a friend, the operation is rejected.

## Given
- A user is authenticated (`client`).
- The user attempts to switch the context.

## When
- The user provides an invalid context type (e.g., something other than `room` or `friend`).

## Then
- The system returns an error message: "context must be room or friend".
- The user's current context remains unchanged.
