# Scenario SC-03 — Attempt to unblock without providing a nickname

**Feature:** FE-05 · **Use case:** UC-02

## Summary

The user attempts to execute the unblock command without providing the required target user's nickname. The system validates the input, detects the missing argument, and returns a usage error message.

## Given

- The user has an active session and is at the command prompt.

## When

- The user enters the command `/user/unblock` without any additional arguments.

## Then

- The system validates the arguments.
- The command execution is aborted due to missing arguments.
- An error message `usage: /user/unblock <user>` is returned.

| 1 | User | Enters `/user/unblock` | N/A |

| 3 | System | Validates argument emptiness via `requireArg` | `client/message.go:89-92` |
| 4 | System | Returns `usage` error | `client/message.go:408` |
