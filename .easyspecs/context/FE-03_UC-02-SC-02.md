# Scenario SC-02 — Fail: user not found

**Feature:** FE-03 · **Use case:** UC-02

## Summary

This scenario covers the failure path when a user attempts to accept a friend request from a target user who cannot be resolved (i.e., does not exist or cannot be found by the provided ID/username).

## Given

- The client is authenticated.
- A friend request from the target user is expected, but the target user cannot be found in the server's list of active clients.

## When

- The user executes the `AcceptFriendRequest` action with a `targetID` or `targetName` that does not correspond to any active client.

## Then

- The server fails to resolve the user.
- The server responds with an error message to the client, indicating that the client was not found.
- The friend request is not accepted.
