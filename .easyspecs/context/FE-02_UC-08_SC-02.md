# Scenario SC-02 — Fail to accept - no invite found

**Feature:** FE-02 · **Use case:** UC-08

## Summary

This scenario covers the behavior when a user attempts to accept an invitation to a room that they have not been invited to. The system must validate the existence of the invite before proceeding.

## Given

- The user has not received an invitation to join the specified room, or the invitation has already been processed/cleared.

## When

- The user calls `AcceptRoomInvite` for a specific `room_id`.

## Then

- The `AcceptRoomInvite` method checks if the room ID exists in the user's `room_invites` map.
- The check returns false.
- An error message "You have not been invited to this room" is sent to the user.
- The operation terminates.
