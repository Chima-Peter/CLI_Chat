# Scenario SC-01 — Switch to existing room context

**Feature:** FE-04 · **Use case:** UC-01

## Summary
The user switches their active context to an existing room where they are currently present.

## Given
The client has provided a valid room name for which they have existing membership.

## When
The client sends a command to switch context to the specified room.

## Then
The system updates the client's current context to `contextRoom` and sets the room to the identified room, clearing any previous friend context. The user receives a `DONE` message confirming the switch.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Sends switch context command to a room | `server/server.go:310` |
| 2 | Server | Validates room membership via `roomByName` or `resolveRoom` | `server/server.go:311-325` |
| 3 | Server | Updates `cl.current_context`, `cl.room`, and clears `cl.current_friend` | `server/server.go:327-331` |
| 4 | Server | Responds with `DONE` message to the client | `server/server.go:333-336` |
