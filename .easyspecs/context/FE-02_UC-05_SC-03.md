# Scenario SC-03 — User fails to delete room because not a member

**Feature:** FE-02 · **Use case:** UC-05

## Summary

The user attempts to delete a room that they are not a member of. The system identifies that the user is not in the room's member list and returns an error.

## Given

- The user is not a member of the room they are attempting to delete.

## When

- The user invokes the action to delete the room.

## Then

- The system detects the user is not a member.
- The system returns an error message: "You are not a part of this room."
