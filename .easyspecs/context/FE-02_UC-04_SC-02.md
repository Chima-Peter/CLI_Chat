# Scenario SC-02 — User fails to leave a room not joined

**Feature:** FE-02 · **Use case:** UC-04

## Summary
The system prevents a user from leaving a room if they are not currently a member of that room, and returns an error message.

## Given
- The user is authenticated (`client`).
- A room exists (`room`).
- The user is not a member of the room (`cl.my_rooms[r.id]` is false).

## When
- The user initiates a request to leave the room (`LeaveRoom` is called).

## Then
- The user receives an error message: "You are not a part of this room."
- *Note:* The current implementation proceeds to execute `DeleteMember` and sends a success message regardless, which may be a defect in the implementation logic.
