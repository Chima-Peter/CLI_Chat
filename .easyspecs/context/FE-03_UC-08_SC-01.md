# Scenario SC-01 — Successfully remove an existing friend

**Feature:** FE-03 · **Use case:** UC-08

## Summary
The user successfully removes an existing friend from their friend list. The system updates the friend list for both the initiating user and the target friend, and sends a confirmation message to the initiator.

## Given
The initiating user (`cl`) and the target user (`friend`) are currently connected and have an established friendship (`cl.friends` contains `friend.id` and `friend.friends` contains `cl.id`).

## When
The initiating user sends a request to remove the friend via the `DeleteFriend` method on the server.

## Then
- The system verifies the friendship exists (`server/client.go:240`).
- The system removes the `friend.id` from `cl.friends` (`server/client.go:248`).
- The system removes the `cl.id` from `friend.friends` (`server/client.go:252`).
- The initiator receives a confirmation message: "Removed <friend.nick> from your friends." (`server/client.go:255`).

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | System (server) | Resolve the target user from ID/name. | `server/server.go:634` |
| 2 | System (client) | Verify existence of friendship. | `server/client.go:240` |
| 3 | System (client) | Remove friend from initiator's list. | `server/client.go:248` |
| 4 | System (client) | Remove initiator from friend's list. | `server/client.go:252` |
| 5 | System (client) | Send confirmation to initiator. | `server/client.go:255` |

## Related code and tests
- `server/client.go`: Implements the `DeleteFriend` logic on the client structure.
- `server/server.go`: Implements the server-side method to resolve user and initiate deletion.
