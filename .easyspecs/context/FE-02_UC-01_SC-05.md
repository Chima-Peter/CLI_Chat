# Scenario SC-05 — Try to join a private room

**Feature:** FE-02 · **Use case:** UC-01

## Summary

When a user attempts to join a room that is configured as private, the system detects this status and prompts the user to provide a password before allowing entry to the room.

## Given

- The room exists and has the `is_private` attribute set to `true`.
- The user is not currently in this room (or is attempting to join).

## When

- The user sends a request to join the private room.

## Then

- The system identifies the room as private.
- The system sends a `GET_ROOM_PASSWORD` message to the client, requesting the room password.
- The room entry process is paused until the user provides the correct password.
