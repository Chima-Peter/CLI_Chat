# Scenario SC-02 — View pending room invites with no invited users

**Feature:** FE-02 · **Use case:** UC-07

## Summary

The room owner requests to see the list of pending room invites. If there are no active invitations for the room, the system returns a message indicating the list of invited users is empty by simply returning the header message without any numbered entries.

## Given

- The room owner is authenticated and is the owner of the room.
- The room exists in the system.
- There are no active invitations for this room (`r.invites` is empty).

## When

- The room owner executes the command to view pending room invites (`SeePendingRoomInvites`).

## Then

- The system retrieves the list of invited users, which is empty.
- The system formats the message using `formatNumberedList` with the header "these are users you invited to this room:" and an empty list of invitees.
- The room owner receives a message containing only the header text.
