# Scenario SC-01 — Successfully block another user

**Feature:** FE-05 · **Use case:** UC-01

## Summary

This scenario describes the successful blocking of another user by the current client. The system validates that the target user is not the current user and not already blocked, then updates the blocked users list.

## Given

- The current client (`cl`) and the target client (`target`) exist.
- The current client is not currently blocking the target client (`hasID(cl.blocked_users, target.id)` is false).
- The current client ID (`cl.id`) is different from the target client ID (`target.id`).

## When

- The `BlockUser` method is invoked on the current client instance with the target client instance as the argument.

## Then

- The target client's ID is added to the current client's `blocked_users` map.
- A success message is sent back to the current client confirming that the target user has been blocked.
