# Scenario SC-01 — Join private room successfully with correct password

**Feature:** FE-02 · **Use case:** UC-02

## Summary
The user attempts to join a private room by providing the correct password. The system validates the password and, if correct, adds the user to the room's member list and updates the user's current room context.

## Given
- A private room exists (`r`).
- The user is authenticated (`cl`).
- The user knows the correct password for the private room.

## When
- The user calls `JoinRoomWithPassword` with the correct password.

## Then
- The system validates that the provided password matches the room's password (`server/rooms.go:121`).
- The user is added to the room's member list (`server/rooms.go:150`).
- The user's `room` field is set to the private room (`server/rooms.go:146`).
- The user is added to `my_rooms` (`server/rooms.go:147`).
- A success message is sent to the user (`server/rooms.go:153`).
- All members in the room are notified that the user joined (`server/rooms.go:154`).
