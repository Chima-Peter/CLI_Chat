# Scenario SC-03 — Invitation fails if user is not room owner

**Feature:** FE-02 · **Use case:** UC-06

## Summary

This scenario covers the case where a user attempts to invite another user to a room, but the user initiating the request is not the room owner. The system correctly denies the invitation request.

## Given

- A room exists, and the `client` (acting as the requester) is a member of that room but not the owner of that room.
- The `client` initiates an invitation request for another user to join the room.

## When

- The system processes the room invitation request initiated by the `client`.
- The system checks if the `client` is the owner of the specified room (`room_data.owner.id != cl.id`).

## Then

- The system rejects the invitation request.
- The system returns an error message: "This action is reserved for only the admin!".
