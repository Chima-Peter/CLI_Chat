# Scenario SC-01 — Send valid message to room

**Feature:** FE-04 · **Use case:** UC-02

## Summary
The user successfully sends a message to a room they are part of. The system validates input, checks membership, broadcasts the message to the room, and confirms the message was sent to the user.

## Given
The user is logged in, has a valid `roomName`, and the `message` is non-empty. The user is a member of the room.

## When
The `SendRoomMessage` function is called with the `client` object, `roomName`, and `message`.

## Then
The message is broadcasted to the room via `room_data.Broadcast(cl, message)`, and a confirmation message is sent to the client via `cl.send_user_message(...)`.
