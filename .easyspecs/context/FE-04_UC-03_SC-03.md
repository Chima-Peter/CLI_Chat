# Scenario SC-03 — Error on empty message

**Feature:** FE-04 · **Use case:** UC-03

## Summary

The system validates that a message is not empty before attempting to send it to the current context (either a room or a friend). If the message is empty or contains only whitespace, an error is returned to the client.

## Given

- The client has established a connection and is potentially in a room context or has a friend context set.
- The client attempts to send a message using the `SendContextMessage` function.

## When

- The user provides an empty message (e.g., `""` or `"   "`).

## Then

- The `SendContextMessage` function trims the message.
- The system detects the trimmed message is empty.
- An error "message cannot be empty" is returned to the client.
