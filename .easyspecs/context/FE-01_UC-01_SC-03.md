# Scenario SC-03 — Attempt to log in with an empty nickname

**Feature:** FE-01 · **Use case:** UC-01

## Summary

The system prevents users from logging in with an empty nickname, or a nickname that consists only of whitespace characters.

## Given

The user has established a connection to the server and is currently not authenticated.

## When

The user attempts to log in by providing an empty string or a string consisting only of whitespace as their nickname.

## Then

The system rejects the attempt, trims the whitespace from the input (if any), detects the empty result, and prompts the user again with a message: "Nickname cannot be empty. Enter a valid nickname: ".
