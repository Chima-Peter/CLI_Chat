# Scenario SC-01 — Successfully accept friend request

**Feature:** FE-03 · **Use case:** UC-02

## Summary
A user accepts a pending friend request from another user, updating both users' friend lists and clearing the request.

## Given
The target user (`cl`) has a pending friend request from the requester (`friend`).
`server/client.go:117` verifies the request existence.

## Then
