# Scenario SC-03 — Fail when already friends

**Feature:** FE-03 · **Use case:** UC-01

## Summary

The system prevents a user from sending a friend request to another user if they are already friends. The system detects this condition during the request process and returns an error message to the initiator.

## Given

- The initiator (User A) and the target user (User B) are already in each other's friend lists.

## When

- User A attempts to send a friend request to User B by calling `SendFriendRequest(B)`.

## Then

- The system identifies that User B is already in User A's friends list (`hasID(cl.friends, friend.id)`).
- The system prevents the request from being sent.
- The system returns an error message: "You are already friends with [User B's nickname]."

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User A | Calls `SendFriendRequest(friend)` | `server/client.go:69` |
| 2 | System | Checks if B is in `cl.friends` | `server/client.go:86` |
| 3 | System | If true, returns "already friends" error | `server/client.go:88` |

## Related code and tests

The logic for this check is implemented in the `SendFriendRequest` method in `server/client.go`. No unit tests are found in the codebase.
