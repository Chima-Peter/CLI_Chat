# Scenario SC-01 — Accept valid room invite

**Feature:** FE-02 · **Use case:** UC-08

## Summary

The user successfully accepts an invitation to join a chat room, provided the invitation exists, the user is not already a member, and the room has capacity.

## Given

- The user (`*client`) has an active invitation for the room, stored in `invitee.room_invites` (`server/rooms.go:303`).
- The room exists and has capacity (`server/rooms.go:319`).
- The user is not already a member of the room (`server/rooms.go:309`).

## When

- The user triggers the `AcceptRoomInvite` action on the room, typically invoked via `server/server.go:250` which is called from the connection handler `server/handle_conn.go:103`.

## Then

- The room accepts the user:
    - The invite is removed from the room's invite list (`server/rooms.go:325`).
    - The user is added to the room's member list (`server/rooms.go:326`).
- The user's state is updated:
    - The invite is removed from the user's `room_invites` (`server/rooms.go:329`).
    - The user's `my_rooms` list is updated (`server/rooms.go:330`).
    - The user's current `room` is set (`server/rooms.go:331`).
- Notifications are sent:
    - The user receives a confirmation message (`server/rooms.go:333`).
    - Existing room members receive a broadcast message that the user has joined (`server/rooms.go:335`).
