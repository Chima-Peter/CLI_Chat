# Scenario SC-02 — Invitation fails if room not found

**Feature:** FE-02 · **Use case:** UC-06

## Summary

The system prevents an invitation from being sent if the specified room does not exist.

## Given

- The user is connected to the server.
- The user is authenticated.

## When

- The user initiates a room invitation request with a `roomID` or `roomName` that cannot be resolved to an existing room.

## Then

- The server fails to resolve the room.
- An error is sent back to the client (`cl.err(err)`).
- No invitation process is initiated.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Send `SendRoomInvite` request with invalid room details | `server/server.go:201` |
| 2 | Server | `resolveRoom` fails | `server/utils.go:211-216` |
| 3 | Server | Return error to client via `cl.err` | `server/server.go:203-206` |

## Related code and tests

- `server/server.go`: Implementation of `SendRoomInvite` which handles room resolution.
- `server/utils.go`: Implementation of `resolveRoom`.
