# Scenario SC-04 — Fail to accept - room full

**Feature:** FE-02 · **Use case:** UC-08

## Summary
The user attempts to accept an invitation to a room, but the invitation fails because the room has reached its maximum member capacity.

## Given
- The user has a valid invitation to a room (`invitee.room_invites[r.id]` exists).
- The user is not already a member of the room.
- The room capacity limit (`r.max_size`) has been reached (`r.isFull()` returns `true`).

## When
- The user triggers the `AcceptRoomInvite` action on the room.

## Then
- The system prevents the user from joining the room.
- The user receives an error message: "Room is full (max %d members).".

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Invokes `AcceptRoomInvite` | `server/rooms.go:302` |
| 2 | System | Checks `isFull()` | `server/rooms.go:319` |
| 3 | System | Sends error message to user | `server/rooms.go:320` |

## Related code and tests
