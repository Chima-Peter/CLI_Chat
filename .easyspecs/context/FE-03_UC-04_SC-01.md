# Scenario SC-01 — Successfully cancel sent friend request

**Feature:** FE-03 · **Use case:** UC-04

## Summary
The user initiates the cancellation of a friend request they previously sent. The system validates the existence of the request and then removes it from both the sender's "sent" list and the receiver's "pending" list.

## Given
- User A (sender) has sent a friend request to User B (receiver).
- User A's `sent_friend_request` map contains User B's ID.
- User B's `pending_friend_requests` map contains User A's ID.

## When
- User A executes the command to cancel the friend request to User B.
- `server.CancelFriendRequest` is invoked.

## Then
- The request is removed from `client.sent_friend_request` for User A.
- The request is removed from `client.pending_friend_requests` for User B.
- Both users receive a confirmation message.
