# Scenario SC-05 — Error when room context is null

**Feature:** FE-04 · **Use case:** UC-03

## Summary

This scenario covers the error handling when a user attempts to send a message while the current context is set to `room` but no specific room is selected (i.e., `room_data` is `nil`).

## Given

- The user is authenticated.
- The user's current context is `contextRoom`.
- The user's `room` (room_data) is `nil`, indicating they have not successfully selected or joined a room yet.

## When

- The user sends a message.

## Then

- The system detects that `room_data` is `nil`.
- The system returns an error message to the user: `use /switch room <name> before sending a message`.
- Message processing is aborted.

| 1 | User | Sends a message | - |

| 3 | System | Checks if `room_data == nil` | `server/server.go:384` |
| 4 | System | Returns error: "use /switch room <name> before sending a message" | `server/server.go:385` |
