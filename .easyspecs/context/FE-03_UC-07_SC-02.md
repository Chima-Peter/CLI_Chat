# Scenario SC-02 — Get empty list of friends

**Feature:** FE-03 · **Use case:** UC-07

## Summary

The user requests their list of friends, but since they have no friends, the system informs them they have no friends.

## Given

- The user is logged in.
- The user has no friends (`cl.friends` is empty).

## When

- The user triggers the `GetFriends` command.

## Then

- The server calls `GetFriends` handler.
- The client-side `GetFriends` function is executed with an empty list of friends.
- The user receives a message "You have no friends."
