# Scenario SC-03 — Attempt switch to non-existent or inaccessible room

**Feature:** FE-04 · **Use case:** UC-01

## Summary

The user attempts to switch the current context to a room that either does not exist globally or to which the user does not have access. The system validates the room's existence and the user's membership.

## Given

- The user has established a connection and is authenticated.
- The user attempts to switch context to a room (`/switch room <name>`).

## When

- The user executes `/switch room <name>`.
- The room `<name>` is not found in the user's current room list (`cl.roomByName(name)`).
- The system attempts to resolve the room globally (`s.resolveRoom("", name)`).
- If the room exists globally, the system checks if the user is a member of the room (`cl.my_rooms[room_data.id]`).

## Then

- If the room does not exist globally, an error "you are not in room: <name>" is returned to the user.
- If the room exists globally but the user is not a member, an error "you are not in room: <name>" is returned to the user.
