# Scenario SC-04 — Fail when request already pending

**Feature:** FE-03 · **Use case:** UC-01

## Summary

User A attempts to send a friend request to User B, but a request is already pending, causing the action to fail with an error.

## Given

- User A and User B are registered users.
- User A has already initiated a friend request to User B (`server/client.go:91-95`).

## When

- User A attempts to send a friend request again to User B (`server/client.go:69`).

## Then

- The system detects the existing pending request (`server/client.go:91`).
- The server returns an error message: "You have already sent a friend request to [User B's nickname]." (`server/client.go:93`).

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User A | Send friend request to User B | `server/client.go:69` |
| 2 | Server | Checks existing sent friend requests | `server/client.go:91` |
| 3 | Server | Denies action and returns error | `server/client.go:93-94` |
