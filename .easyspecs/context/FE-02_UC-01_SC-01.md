# Scenario SC-01 — Join public room successfully

**Feature:** FE-02 · **Use case:** UC-01

## Summary

The user initiates a request to join a public room. If the room is not full and the user is not already in it, they are added to the room's members list, their current room is updated, and a welcome message is sent.

## Given

- The room is public (`is_private` is `false`).
- The room is not full (number of members is less than `max_size` if `max_size > 0`).
- The user is not already a member of this room.

## When

- The user calls `JoinRoom(cl *client)` on a room instance.

## Then

- The user is added to `r.members`.
- The user's `cl.room` is set to the current room.
- The user receives a `DONE` message with a welcome notification.
- Existing members in the room receive a notification via `Broadcast` that the user has joined.
