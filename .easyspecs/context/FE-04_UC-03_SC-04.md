# Scenario SC-04 — Error when no context set

**Feature:** FE-04 · **Use case:** UC-03

## Summary

When a user attempts to send a message without having selected a valid context (room or friend) via the `/switch` command, the system denies the request and returns an error informing the user to switch context first.

## Given

- The client has not successfully initialized a context (`ctx` is neither `contextRoom` nor `contextFriend`).

## When

- The user attempts to send a message.

## Then

- The system triggers an error indicating that a room or friend context must be switched to first: "use /switch room|friend <name> before sending a message".
