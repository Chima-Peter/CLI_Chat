# Scenario SC-01 — Login with an empty nickname

**Feature:** FE-01 · **Use case:** UC-02

## Summary
The system rejects login attempts where the provided nickname is empty or consists solely of whitespace, ensuring all users have a valid identifier.

## Given
The user is at the login prompt and has not yet authenticated.

## When
The user submits a nickname that is either an empty string or contains only whitespace characters (e.g., `"  "`).

## Then
The system detects the empty nickname, rejects the input, and re-prompts the user with a message indicating the nickname cannot be empty.
