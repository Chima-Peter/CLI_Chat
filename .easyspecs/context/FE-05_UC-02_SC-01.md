# Scenario SC-01 — Successfully unblock a blocked user

**Feature:** FE-05 · **Use case:** UC-02

## Summary
The user successfully unblocks a previously blocked user by sending the `/user/unblock` command with the target user's nickname. The system validates the input, confirms the target user is indeed blocked, and removes them from the block list.

## Given
- The target user is present in the current user's `blocked_users` list.

## When
- The user issues the `/user/unblock <nickname>` command.

## Then
- The backend identifies the `UNBLOCK_USER` action.
- The backend validates the presence of the nickname argument.
- The target user is removed from the `blocked_users` map in the `client` struct.
- A success message is sent back to the user via `send_user_message`.
