# Scenario SC-02 — Decline non-existent room invite

**Feature:** FE-02 · **Use case:** UC-09

## Summary

The user attempts to decline an invitation to a room, but they have not received any invitation for that specific room. The system should reject the request and inform the user.

## Given

- The user exists in the system.
- The room exists in the system.
- The user has **not** received an invitation for this specific room (`invitee.room_invites[r.id]` does not exist).

## When

- The user triggers the `DeclineRoomInvite` action for the room.

## Then

- The system detects that the user has not been invited.
- The system returns an error message: "You have not been invited to this room".
- The request is terminated.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Invokes `DeclineRoomInvite(r)` | `server/rooms.go:338` |

| 3 | System | Returns error "You have not been invited to this room" | `server/rooms.go:341` |
