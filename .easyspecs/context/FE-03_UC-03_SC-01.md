# Scenario SC-01 — Successfully reject a pending friend request

**Feature:** FE-03 · **Use case:** UC-03

## Summary

The user initiates a request to reject a pending friend request from another user. The server resolves the target user and, if successful, instructs the client to reject the request.

## Given

A client (`cl`) has a pending friend request from a user identified by `targetID` and `targetName`.

## When

The client invokes `RejectFriendRequest` on the server with the `targetID` and `targetName`.

## Then

The server resolves the target user and instructs the client to reject the friend request from that target.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Calls `RejectFriendRequest` with `targetID`, `targetName`. | `server/server.go:594` |
| 2 | Server | Calls `s.resolveUser(targetID, targetName)`. | `server/server.go:595` |
| 3 | Server | Calls `cl.RejectFriendRequest(target)` upon successful resolution. | `server/server.go:600` |
