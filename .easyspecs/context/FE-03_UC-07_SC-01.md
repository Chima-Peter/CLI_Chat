# Scenario SC-01 — Get list of friends

**Feature:** FE-03 · **Use case:** UC-07

## Summary
The user requests their list of friends. The system retrieves the friends IDs, maps them to user objects, and returns the populated list of friends to the client.

## Given
- The user is logged in.
- The user has one or more friends defined in their client's friend set `server/server.go:628`.

## When
- The client initiates a request to get their friends.
- The server calls `server.GetFriends(cl)` `server/server.go:626`.

## Then
- The server retrieves the user's friend IDs and maps them to user objects `server/server.go:630`.
- The server sends the populated friend list to the client using `client.GetFriends(users)` `server/server.go:630`.
- The client receives the `send_user_message` with the friend list and a formatted string `server/client.go:231-235`.
