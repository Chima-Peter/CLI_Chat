# Scenario SC-02 — Log out while authenticated

**Feature:** FE-01 · **Use case:** UC-03

## Summary

When an authenticated user requests to log out, the server confirms the logout action and subsequently terminates the client connection.

## Given

- The client is currently in an authenticated state.

## When

- The user sends a `LOGOUT` action request.

## Then

- The server sends a confirmation message: "Logged out."
- The server closes the connection with the client.

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Sends `LOGOUT` action | `server/handle_conn.go:78` |
| 2 | System | Sends "Logged out." confirmation | `server/handle_conn.go:79` |
| 3 | System | Closes client connection | `server/handle_conn.go:80` |

## Related code and tests

The handling of the logout request is implemented in `server/handle_conn.go`. When the client is authenticated (`cl.authenticated` is true), the `LOGOUT` case triggers the sending of a "Logged out." message followed by returning `true`, which orchestrates the connection termination.
