# Scenario SC-01 — List sent friend requests when requests exist

**Feature:** FE-03 · **Use case:** UC-06

## Summary
When a user requests to view their sent friend requests, the server retrieves the list of pending sent friend requests and sends them to the client.

## Given
The user is authenticated and has one or more active sent friend requests. These requests are tracked in the client's `sent_friend_request` set.

## When
The client invokes the `SeeSentFriendRequests` method on the server.

## Then
The server fetches the IDs of the sent friend requests from the client's state, resolves the corresponding user objects, and notifies the client with the list of sent requests.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Invokes `SeeSentFriendRequests` | `server/server.go:619` |
| 2 | Server | Retrieves sent friend requests | `server/server.go:621` |
| 3 | Server | Sends fetched requests to client | `server/server.go:623` |
