# Scenario SC-01 — Decline room invite successfully

**Feature:** FE-02 · **Use case:** UC-09

## Summary

The user successfully declines a valid room invite. The system removes the invitation for both the room and the user, and sends a confirmation message back to the user.

## Given

A user has a pending invite for a room that they are not yet part of.

## When

The user invokes the decline invite action for that specific room.

## Then

The invitation is removed from both the room's invite list and the user's invite list, and the user receives a success message.
