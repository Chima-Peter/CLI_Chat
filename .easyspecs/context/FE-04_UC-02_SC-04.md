# Scenario SC-04 — Fail when user not in room

**Feature:** FE-04 · **Use case:** UC-02

## Summary
When a user attempts to send a message to a room they are not currently a member of, the system denies the action and returns an error indicating the user is not in the room.

## Given
The user is connected to the server but has not joined the target room, or the room membership has not been established for this client.

## When
The client sends a message request specifying a `roomName` for a room they are not part of.

## Then
The server checks the user's room membership (`cl.my_rooms`). Finding the user is not in the specified room, the server rejects the request and sends an error message: `you are not in room: <roomName>`.
