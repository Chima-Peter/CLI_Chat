# Scenario SC-02 — Attempt to unblock a user not currently blocked

**Feature:** FE-05 · **Use case:** UC-02

## Summary

The user attempts to unblock another user who is not currently in their block list. The operation is rejected by the system, and an error message is returned to the user.

## Given

- The user is authenticated.
- The target user exists.
- The target user is **not** present in the current user's `blocked_users` map.

## When

- The user executes the command `/user/unblock <nickname>` in the client.

## Then

- The client routes the request to the server as a `UNBLOCK_USER` action.
- The server checks if the target user's ID is in the `blocked_users` map of the current client.
- Since the target user is not blocked, the server sends an error message `"<nickname> is not blocked."` back to the user.
