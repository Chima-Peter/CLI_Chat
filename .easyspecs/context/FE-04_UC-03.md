# Use case UC-03 — Send message to current context (Feature FE-04)

## Summary

The actor sends a message to the currently selected room or friend context, allowing for targeted communication without needing to specify the recipient for every message.

## Actors and stakeholders

- **Client (Actor):** The authenticated user sending the message.
- **Recipient:** Either the members of the current room or a specific friend, depending on the current context.

## Preconditions

- **Authentication:** The client must be successfully authenticated.
- **Context:** The client must have a current context (`contextRoom` or `contextFriend`) already set using the `/switch` command.

## Data inputs and validation

- **Message (Required):** The text content of the message.
  - **Validation:** Must not be empty or consist only of whitespace.
  - **Failure:** Returns an error message to the client if empty.

## Main flow

1. The client sends a message through the active connection.
2. The server dispatches the request to `SendContextMessage`.
3. The server checks the current context of the client.
4. If in a room context, the message is broadcast to the room.
5. If in a friend context, the message is sent directly to the friend.

## Code flow

### Implementation Order

1. **Entrypoint:** `server/handle_conn.go` receives `SEND_MSG` action in `dispatchMessage` (lines 128-129).
2. **Context Retrieval:** `server/server.go:369` calls `SendContextMessage(cl, p.Message)`.
3. **Input Validation:** The message is trimmed and checked for emptiness (lines 370-374).
4. **Context Check:**
   - The server acquires a read lock on the client (`cl.mu.RLock()`) to retrieve `current_context`, `room`, and `current_friend` (lines 376-380).
5. **Dispatching:**
   - **Room:** If `contextRoom`, it calls `room_data.Broadcast(cl, message)` (line 388).
   - **Friend:** If `contextFriend`, it calls `cl.MessageFriend(friend, message)` (line 396).

## Errors and edge cases

- **Empty message:** Returns "message cannot be empty" (line 372).
- **No context:** Returns "use /switch room|friend <name> before sending a message" (line 399).
- **Room context not set:** Returns "use /switch room <name> before sending a message" (line 385).
- **Friend context not set:** Returns "use /switch friend <name> before sending a message" (line 393).
