# Scenario SC-03 — Fail when room name is empty

**Feature:** FE-04 · **Use case:** UC-02

## Summary
The system rejects a request to send a message if the `roomName` parameter is empty or contains only whitespace.

## Given
- The user is authenticated.
- The user is attempting to send a message.

## When
- The user provides an empty string or a string consisting only of whitespace as the `roomName` in the request.

## Then
- The system returns an error: "room name is required".
- The message sending process is terminated, and the message is not sent to the room.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Attempts to send a message with an empty or whitespace-only room name. | N/A |
| 2 | System | Executes `strings.TrimSpace(roomName) == ""` check. | `server/server.go:519` |
| 3 | System | Calls `cl.err(fmt.Errorf("room name is required"))`. | `server/server.go:520` |
| 4 | System | Terminates process with `return`. | `server/server.go:521` |
