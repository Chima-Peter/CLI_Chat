# Scenario SC-02 — Fail when message is empty

**Feature:** FE-04 · **Use case:** UC-02

## Summary
The system rejects room message submission if the message content is empty or only whitespace.

## Given
The client has initiated a `SendRoomMessage` request with an empty or blank message string.

## When
The `SendRoomMessage` function is called with the empty message.

## Then
The system triggers an error indicating "message cannot be empty" and terminates the message sending process for that request.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Sends `SendRoomMessage` with empty `message`. | `server/server.go:513` |
| 2 | System | Trims message and detects empty string. | `server/server.go:514-515` |
| 3 | System | Returns "message cannot be empty" error to client. | `server/server.go:516` |

## Related code and tests

The implementation of this validation is located in `server/server.go` within the `SendRoomMessage` method.
