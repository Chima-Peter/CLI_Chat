# Scenario SC-03 — Fail: no pending request from user

**Feature:** FE-03 · **Use case:** UC-02

## Summary

The user attempts to accept a friend request from another user. The system verifies if there is a pending friend request from that user. If no such request exists in the user's pending friend requests, the system denies the action and returns an error message.

## Given

- The user has an authenticated session.
- The `client` object for the user exists, and `pending_friend_requests` map does not contain the `friend.id` of the target user.

## When

- The user calls `AcceptFriendRequest` (via `server/client.go:115`) with a target `friend` user.

## Then

- The system verifies the existence of the request in `pending_friend_requests` (`server/client.go:117`).
- The check `!exists` evaluates to true (`server/client.go:119`).
- The system returns an error message: "You have not received a friend request from this user." (`server/client.go:120`).

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Calls `AcceptFriendRequest` with non-existent request sender. | `server/client.go:115` |
| 2 | System | Checks `pending_friend_requests` for sender ID. | `server/client.go:117` |
| 3 | System | Detects absence of request and triggers error. | `server/client.go:119-122` |
