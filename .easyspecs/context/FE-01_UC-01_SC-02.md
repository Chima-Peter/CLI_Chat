# Scenario SC-02 — Attempt to log in while already logged in

**Feature:** FE-01 · **Use case:** UC-01

## Summary
When a client that is already authenticated attempts to call the login functionality again, the system should prevent the re-authentication and notify the user to log out first.

## Given
The client is already authenticated (`cl.authenticated` is `true`).

## When
The client sends a login request (e.g., provides a nickname) while already authenticated.

## Then
The system detects that the client is already authenticated, stops further processing of the login request, and sends a notification to the client prompting them to log out first.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Sends login request | `server/handle_conn.go:164` |
| 2 | Server (`handleLogin`) | Checks `cl.authenticated` | `server/handle_conn.go:165` |
| 3 | Server (`handleLogin`) | Sends "You are already logged in..." | `server/handle_conn.go:166` |
| 4 | Server (`handleLogin`) | Returns early | `server/handle_conn.go:167` |
