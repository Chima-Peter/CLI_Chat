# Scenario SC-04 — Check status of blocked online user

**Feature:** FE-05 · **Use case:** UC-03

## Summary
This scenario describes the system's behavior when a user requests the status of another user whom they have blocked and who is currently online.

## Given
- The requesting user (`cl`) has blocked the target user (`target`).
- The target user (`target`) is currently online.

## When
- The requesting user (`cl`) calls `GetUserStatus(target)` to retrieve the status of the target user.

## Then
- The system correctly identifies that the target user is blocked (`isBlocked = true`).
- The system correctly identifies that the target user is online (`online = true`).
- The system sends a message to the requesting user containing both the online status and the blocked status of the target user.
