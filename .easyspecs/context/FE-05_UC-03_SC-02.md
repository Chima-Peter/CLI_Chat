# Scenario SC-02 — Check status of unblocked online user

**Feature:** FE-05 · **Use case:** UC-03

## Summary
Verify that when a client requests the status of another user who is currently online and not in the requester's blocked list, the returned status correctly reflects their online state and unblocked status.

## Given
- The target user is online (`target.online = true`).
- The target user is not in the requester's blocked list (`hasID(cl.blocked_users, target.id)` returns false).

## When
- The client calls `GetUserStatus(target)` on the target user.

## Then
- The `GetUserStatus` function processes the target's online state as `true`.
- The `isBlocked` flag is calculated as `false`.
- A message is sent to the client containing `online: true`, `blocked: false`, and appropriate room information.
