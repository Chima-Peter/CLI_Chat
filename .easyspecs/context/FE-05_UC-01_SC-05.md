# Scenario SC-05 — Attempt to block a non-existent user

**Feature:** FE-05 · **Use case:** UC-01

## Summary
When a user attempts to block a target user that does not exist in the system, the server fails to resolve the target, reports an error to the client, and aborts the block operation.

## Given
The user is connected to the server. The target user ID/name provided by the user does not correspond to any active user.

## When
The user sends a request to block the target user.

## Then
The server-side `BlockUser` method attempts to resolve the target. Since the target does not exist, an error is returned by `resolveUser`. The server calls `cl.err(err)` to report this failure to the requester, and the operation terminates without blocking any user.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Sends `BlockUser` request with invalid target identifier | N/A |
| 2 | Server (`BlockUser`) | Calls `s.resolveUser(targetID, targetName)` | `server/server.go:652` |
| 3 | Server (`resolveUser`) | Returns error for non-existent user | `server/server.go:653` |
| 4 | Server (`BlockUser`) | Calls `cl.err(err)` and returns | `server/server.go:654-655` |
