# Scenario SC-01 — No pending friend requests

**Feature:** FE-03 · **Use case:** UC-05

## Summary

The user initiates a request to see their pending incoming friend requests. When the user has no pending requests, the system responds with an empty list or indicates that there are no requests to display.

## Given

The user is authenticated and connected to the server. The user's list of `pending_friend_requests` is empty.

## When

The user triggers the `SEE_FRIEND_REQUEST` action.

## Then

The system retrieves the empty list of pending friend requests and sends this result back to the user via the `FetchPendingRequests` method on the client.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Triggers `SEE_FRIEND_REQUEST` | `server/handle_conn.go:142-143` |
| 2 | System | Calls `SeePendingFriendRequests` | `server/server.go:612` |
| 3 | System | Retrieves empty `pending_friend_requests` | `server/server.go:613-615` |
| 4 | System | Calls `FetchPendingRequests` with empty set | `server/server.go:616` |
