# Scenario SC-01 — Send message to room context

**Feature:** FE-04 · **Use case:** UC-03

## Summary

The user sends a message while the current context is set to a room. The system validates that a room is selected and then broadcasts the message to the room participants.

## Given

- The client has a `current_context` set to `contextRoom`.
- A room context (`cl.room`) is successfully established/selected.

## When

- The user initiates a message sending action with a non-empty message string.

## Then

- The system broadcasts the message to all participants in the current room via `room_data.Broadcast`.
- The system confirms the message delivery to the sender with a "You: [message]" format.
