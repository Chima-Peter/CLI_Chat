# Scenario SC-02 — Deny update if not owner

**Feature:** FE-02 · **Use case:** UC-03

## Summary
A user who is not the owner of the room attempts to update the room's settings (name or max size). The system denies the request.

## Given
- A room exists, and `r.owner.id` is the ID of the room owner.
- A user `cl` attempts to call `EditRoom` on the room, where `cl.id != r.owner.id`.

## When
- The client `cl` invokes `EditRoom`.

## Then
- The system checks if the client is the owner (`r.owner.id != cl.id`).
- Since the client is not the owner, the system returns an error message: "Only the room owner can edit this room."

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Client | Calls `EditRoom` with new settings. | `server/rooms.go:157` |
| 2 | System | Checks `if r.owner.id != cl.id`. | `server/rooms.go:158` |
| 3 | System | Returns error "Only the room owner can edit this room." | `server/rooms.go:159-160` |
