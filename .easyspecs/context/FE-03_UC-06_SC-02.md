# Scenario SC-02 — List sent friend requests when no requests exist

**Feature:** FE-03 · **Use case:** UC-06

## Summary

When a user requests to list their sent friend requests, and they have no pending sent requests, the system informs them that they have no sent requests.

## Given

- The user has an empty set of sent friend requests.
- The `cl.sent_friend_request` map in `server/client.go` is empty.

## When

- The user triggers the action to see sent friend requests, which invokes `server.SeeSentFriendRequests`.

## Then

- The server calls `cl.FetchSentRequests` with an empty slice of users.
- The `cl.FetchSentRequests` method detects the empty list and sends a message to the client: "You have no sent requests."

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | User | Triggers request to see sent friend requests | `server/server.go:619` |
| 2 | Server | Retrieves empty `sent_friend_request` set | `server/server.go:620-621` |
| 3 | Server | Calls `FetchSentRequests` with empty slice | `server/server.go:623` |
| 4 | Client | Receives empty slice, sends "You have no sent requests." message | `server/client.go:197-199` |

## Related code and tests
