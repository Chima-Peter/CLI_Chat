# Scenario SC-02 — List existing pending friend requests

**Feature:** FE-03 · **Use case:** UC-05

## Summary

This scenario describes the process when a user has one or more incoming pending friend requests and requests to view them. The server retrieves the IDs of the pending requests from the user's client state and fetches the corresponding user details.

## Given

- The user is authenticated and connected to the server.
- The user has one or more pending incoming friend requests.

## When

- The user triggers the action to see their pending friend requests.
- The server calls `SeePendingFriendRequests(cl *client)` in `server/server.go`.

## Then

- The server locks the client to safely access `pending_friend_requests`.
- The server retrieves the list of user IDs for the pending requests.
- The server resolves the user objects for those IDs and calls `cl.FetchPendingRequests` to send the details back to the client.
