# Scenario SC-04 — Invitation fails if invitee not found

**Feature:** FE-02 · **Use case:** UC-06

## Summary
This scenario covers the failure path where a room owner attempts to send a room invitation to a user that does not exist in the system. The system validates the existence of the invitee before proceeding with the invitation.

## Given
- A room exists (identified by `roomID` or `roomName`).
- The current user (the requester) is the owner of the room.

## When
- The room owner executes the `SendRoomInvite` command for a user (`memberID` or `memberName`) that cannot be resolved by the system.

## Then
- The system fails to resolve the invitee.
- An error is returned to the room owner, and the invitation process is terminated.

## Step-by-step

| Step | Actor / system | Expected | Evidence |
| --- | --- | --- | --- |
| 1 | Owner | Initiates `SendRoomInvite` for a non-existent user | `server/server.go:201` |
| 2 | System | Validates room ownership | `server/server.go:208-211` |
| 3 | System | Attempts to resolve the invitee | `server/server.go:213` |
| 4 | System | Fails to resolve the user and returns an error | `server/server.go:214-216` |

## Related code and tests
- `server/server.go`: Main invitation handling logic.
